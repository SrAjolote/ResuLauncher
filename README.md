# Dbr Launcher — Dragon Block Resurrection

Repositorio oficial de descargas y recursos del servidor **Dragon Block Resurrection** (Minecraft Forge 1.7.10).

## 📥 Descarga del Launcher
Puedes descargar la versión portable lista para jugar desde la sección de **[Releases](https://github.com/SrAjolote/ResuLauncher/releases)**:
- **`Dbr-Launcher-Portable.zip`**: Solo descomprime y ejecuta `Dbr Launcher.exe`. No requiere instalación.

---

## 🎮 Contenido del Repositorio
- 📁 **`MODS/`**: Colección completa de mods optimizados para el servidor (DragonBlockC 1.4.85, JRMCore, CustomNPCs Plus, unimixins, armaduras, transformaciones y utilidades).
- 🎨 **`DbrTexture v6.zip`**: Pack de texturas oficial con GUI temática de Dragon Ball y Minecraft (barras de Ki, release, vida, estamina y menús).
- 🎵 **`cancion.mp3`**: Pista musical de fondo temática para el launcher.

---

## ⚡ Características del Launcher
- **Cero Instalación**: Funciona directamente en cualquier carpeta o memoria USB.
- **Auto-conexión**: Conexión al servidor `dragonblock.online:25625`.
- **Textura Automática**: Carga y activa automáticamente `DbrTexture v6.zip` en las opciones de Minecraft.
- **Sincronización de Mods**: Si agregas o actualizas un mod en la carpeta `MODS/`, el launcher lo detecta y lo actualiza automáticamente al dar clic en **JUGAR**.
- **Música integrada**: Reproductor con botón de silenciar y control de volumen.
- **Login Microsoft y No-Premium**: Compatible con ambos métodos (incluye botón para copiar el código de inicio de sesión de Microsoft en un clic).
